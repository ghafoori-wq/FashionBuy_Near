# FashionBuy — 3D Luxury AI Atelier & NEAR Commerce Studio     
WEB Link: https://fashionbuy-near.onrender.com/

**FashionBuy** is an interactive 3D WebGL fashion studio combining AI styling, virtual try-on, parametric sewing pattern drafting, and on-chain payments powered by **NEAR Protocol**.

## Key Features
- **3D Interactive Atelier:** Real-time 3D studio environment with customizable mannequins, seasonal lookbooks, and spatial UI cards.
- **AI Stylist & Virtual Try-On:** Personalized outfit recommendations, body-fit compatibility scoring, and AI-generated try-on previews.
- **Parametric Sewing & Smart Glasses AR:** Custom sewing pattern generation from 5 body measurements with live AR distance-locked fabric projection.
- **NEAR Protocol Checkout:** Direct wallet integration via NEAR JS SDK and Meteor Wallet supporting real on-chain NEAR Testnet transactions.

## Tech Stack
- **Frontend:** Three.js (WebGL & CSS3DRenderer), WebXR, HTML5, CSS3, JavaScript
- **Blockchain:** NEAR Protocol (NEAR Testnet, Meteor Wallet Integration)
- **Backend & AI:** Node.js, Generative AI Fashion & Pattern Engine
